How the price is built. Each row's headline number is the cheapest get-in we can see for that event across every marketplace in the daily cross-source snapshot (event_listing_snapshot_daily — EVO, StubHub, Gametime, VividSeats, TickPick, Ticketmaster, SeatGeek). vs usual compares it against that event's own trailing 30-day median get-in — the same idea as Google Flights' "prices are currently low", but per event rather than per route, and drawn from an indefinitely-retained history. Expanding a row adds the live layer: per-marketplace inventory landed by the TicketsData pollers (ticketsdata_listings_snapshots) plus our own EVO book, and the cheapest real listings that seat your ticket count. Live coverage is credit-budgeted, so events without a recent poll fall back to their daily snapshot prices and say so. Read-only — this page never triggers an upstream fetch.
