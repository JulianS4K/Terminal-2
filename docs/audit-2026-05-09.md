## 3. Security — JS safety scan

### 🚨 BLOCKING — DOM-XSS in `shop.html` chatbot

**File**: `static/_proposals/shop.html:565` and `:576`

```javascript
// L576 — sendChat() takes raw user input from the chat textbox:
const t = input.value.trim();
log.innerHTML += `<div class="chat-msg"><div class="role">you</div><div>${t}</div></div>...`;
```

A retail user typing `<img src=x onerror="alert(document.cookie)">` into the chatbox executes script in their session. Because the retail site is the most likely target for untrusted input AND skeletons get copied into production, **this must be fixed before merge**.

**Fix** (5-line edit):

```javascript
function escapeHTML(s) {
  return String(s).replace(/[&<>"']/g, c =>
    ({ '&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#39;' }[c]));
}
// then:
log.innerHTML += `<div class="chat-msg"><div class="role">you</div><div>${escapeHTML(t)}</div></div>...`;
```

Or use `textContent` for the user-typed portion:

```javascript
const msg = document.createElement('div');
msg.className = 'chat-msg';
const role = document.createElement('div'); role.className = 'role'; role.textContent = 'you';
const body = document.createElement('div'); body.textContent = t;
msg.append(role, body);
log.append(msg);
```

Same pattern in `openChat(prefill)` at L565 — `prefill` is currently a static literal but a future wiring (URL params, deep links) would expose it.

### ⚠️ NOTE (not blocking) — inline `onclick` with future-data hazards

`undelivered.html` has 7 inline `onclick="openDrawer('sg_44218')"` patterns. The IDs are static literals in the skeleton, so safe today. **When wired to live data**, the IDs come from `unified_orders.source_order_id` — if any source ever returns an attacker-controlled ID string, the inline handler becomes XSS-prone.

**Mitigation when wiring**: switch to `addEventListener` with `data-order-id` attributes:

```html
<tr class="t-red" data-order-id="sg_44218" data-action="open-drawer">…</tr>
```
```javascript
table.addEventListener('click', (e) => {
  const tr = e.target.closest('tr[data-action="open-drawer"]');
  if (tr) openDrawer(tr.dataset.orderId);
});
```

Note this in the wiring PR; not a blocker today.
